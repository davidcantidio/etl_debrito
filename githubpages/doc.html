Guia para o Claude Code: publicar um Gantt no GitHub Pages (a partir da documentação oficial) Objetivo: criar (ou usar) um repositório, habilitar o GitHub Pages e publicar uma página que renderize um Gantt em Mermaid com a evolução do projeto.

1) Premissas e limites GitHub Pages hospeda sites estáticos diretamente de um repositório. Está disponível em repositórios públicos (Free) e também em privados conforme o plano. GitHub Docs

O site publica a partir de uma fonte de publicação (branch/pasta) ou via GitHub Actions. GitHub Docs +1

Respeite limites (tamanho/tempo de build e renderização). GitHub Docs +1

Mermaid é suportado nativamente no GitHub em arquivos Markdown — inclusive gantt — via bloco de código mermaid. GitHub Docs +1

3) Habilitar o GitHub Pages Opção A — Publicação por Branch/Pasta No repositório, abra Configurações → Pages.

Em Source, selecione o branch (ex.: main) e, se quiser, a pasta (ex.: /docs). Salve. GitHub Docs

Opção B — Publicação por GitHub Actions Use um workflow de deploy (recomendado quando usa Jekyll/geradores). O Pages hoje usa Actions por padrão nos builds Jekyll. GitHub Docs +1

4) (Opcional) Jekyll e Tema O Pages tem suporte integrado ao Jekyll (Markdown + Liquid) e facilita aplicar temas. GitHub Docs +1

6) Publicação via GitHub Actions (opcional, recomendado)

Crie .github/workflows/pages.yml:

```yaml name: Deploy GitHub Pages

on: push: branches: [ “main” ] workflow_dispatch:

permissions: contents: read pages: write id-token: write

concurrency: group: “pages” cancel-in-progress: false

jobs: build: runs-on: ubuntu-latest steps: - name: Checkout uses: actions/checkout@v4

  # (Opcional) Se usar Jekyll, configure Ruby e build
  - name: Setup Ruby
    uses: ruby/setup-ruby@v1
    with:
      ruby-version: '3.3'
  - name: Install Jekyll
    run: |
      gem install jekyll bundler
      bundle init
      bundle add jekyll
  - name: Build site
    run: |
      jekyll build -s . -d ./_site

  - name: Setup Pages
    uses: actions/configure-pages@v5
  - name: Upload artifact
    uses: actions/upload-pages-artifact@v3
    with:
      path: _site   deploy:
environment:
  name: github-pages
  url: $
needs: build
runs-on: ubuntu-latest
steps:
  - name: Deploy to GitHub Pages
    id: deployment
    uses: actions/deploy-pages@v4 O Pages usa Actions para compilar Jekyll; verifique logs caso haja erros de build.  GitHub Docs

9) Boas práticas para renderização Mermaid Prefira blocos pequenos (renderização de arquivos grandes pode falhar ou exibir como texto). GitHub Docs

Evite plugins Mermaid adicionais quando usar Mermaid nativo do GitHub. GitHub Docs

Para Jekyll, não é obrigatório script extra para Mermaid — a renderização é do próprio GitHub na página final. GitHub Docs
